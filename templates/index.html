What happens when you push

  1. GitHub Actions starts. The workflow in .github/workflows/ci-cd.yml runs on every push and pull request to main.
  2. The test job runs. It installs Python dependencies and runs the Pytest suite.
  3. Failed tests stop everything. The deploy job never starts, so broken code never reaches Render.
  4. The deploy job runs. Only for pushes to main after tests pass, it calls the Render deploy hook stored in GitHub Secrets.
  5. Render rebuilds the app. This page shows the new version when the deploy finishes.
Built with Python, Flask, Pytest, GitHub Actions and Render.
